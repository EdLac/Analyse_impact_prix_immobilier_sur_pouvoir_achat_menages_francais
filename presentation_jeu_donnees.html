PRÉSENTATION DU JEU DE DONNÉES

Observatoire Stratégique de l'Immobilier Français

1. SOURCE ET ORIGINE DES DONNÉES

Le projet repose sur trois sources de données publiques officielles :

1.1 Données Macroéconomiques France (INSEE)

  • Source : Institut National de la Statistique et des Études Économiques
  • Format : Fichier Excel (Dataprojetglobalhorsdvf.xlsx)
  • Fiabilité : Données officielles, mises à jour régulièrement
  • Périmètre géographique : France métropolitaine

1.2 Taux d'Intérêt (Banque de France)

  • Source : Banque de France - Direction des statistiques monétaires
  • Format : Fichier Excel (tauxintérêtsBdFpour compléter années 2020-25.xlsx)
  • Type de taux : Taux d'intérêt immobiliers long terme
  • Utilisation : Complète les données macroéconomiques pour la période 2020-2025

1.3 Demande de Valeurs Foncières - DVF (DGFiP)

  • Source : Direction Générale des Finances Publiques
  • Format : Fichiers TXT multiples (séparateur "|", encodage UTF-8)
  • Contenu : Transactions immobilières enregistrées par les notaires
  • Périmètre géographique : 8 départements d'Île-de-France (75, 77, 78, 91, 92, 93, 94, 95)
  • Type d'opérations : Ventes d'appartements uniquement (filtre appliqué)

4. QUALITÉ DES DONNÉES ET VALEURS MANQUANTES

4.1 Données Macroéconomiques

Traitement des valeurs manquantes :

Variable Taux de complétude Méthode de traitement
Indicateurs principaux ~95-100% Interpolation linéaire pour gaps mineurs
Taux_Immobilier (2020-2025) Complété via BdF Fusion avec données Banque de France
Dette_Immobiliere (années anciennes) ~90% Conservé tel quel (pas d'interpolation artificielle)

Points de vigilance : - Les données les plus récentes (2024-2025) peuvent être des estimations provisoires (INSEE) - Certains indicateurs changent de base de calcul au fil du temps (détection automatique base 1 vs base 100)

4.2 Données DVF

Filtrage et nettoyage appliqués :

Étape Critère Impact
Filtrage géographique Départements IdF uniquement Conservation ~8-10% du volume national
Filtrage typologique Ventes + Appartements Suppression maisons, terrains, locaux commerciaux
Détection outliers Méthode IQR (percentiles 1%-99%) Suppression ~2-5% des transactions extrêmes
Bornes réalistes 500 €/m² < Prix < 25 000 €/m² Élimination erreurs de saisie
Valeurs nulles Surface > 0 et Valeur > 0 Suppression transactions incomplètes

Taux de valeurs manquantes après nettoyage : - Prix_m2 : 0% (calculé uniquement sur lignes complètes) - Commune : ~0-2% (quelques transactions sans géolocalisation précise) - Code_postal : ~0-2% (idem)

5. AUTRES ÉLÉMENTS DESCRIPTIFS PERTINENTS

5.1 Caractéristiques Techniques

  • Format de sortie principal : 15 DataFrames distincts générés par le pipeline ETL
  • Exports disponibles : CSV pour chaque DataFrame (répertoire DATA_CLEAN2/)
  • Granularité temporelle : Annuelle (macro) / Transactionnelle puis agrégée (DVF)
  • Granularité géographique : Nationale (macro) / Département + Commune (DVF)

5.2 Agrégations Disponibles

L'application génère automatiquement :

Vue agrégée Description Utilisation
df_macro_analyse Données France complètes (1990-2025) Analyses longue période
df_macro_20 Données France (20 dernières années) Focus récent
df_agg_idf Prix médians IdF par année Évolution régionale
df_agg_dept Prix médians par département et année Comparaisons départementales
df_agg_commune Prix médians par commune et année Analyses micro-locales
df_top10_communes Top 10 communes les plus chères par année Benchmark haut de gamme
df_global_5 Union macro + DVF (5 dernières années) Analyses croisées récentes

5.3 Cohérence et Validation

Contrôles qualité implémentés : - ✅ Validation cohérence temporelle (années croissantes, pas de gaps) - ✅ Détection changements de base (indices base 1 vs base 100) - ✅ Normalisation codes départements (gestion variantes) - ✅ Gestion robuste des erreurs d'encodage - ✅ Traçabilité complète des transformations (logs détaillés)

Limites connues : - Données DVF disponibles à partir de 2014 seulement (historique limité) - Certaines petites communes ont peu de transactions (biais échantillon) - Prix au m² fortement influencés par typologie des biens (studio vs 5 pièces)
